# W4A8 性能报告（实际 XSim 周期）

时钟仿真周期为 10 ns；100 MHz 仅作为约束目标。供数模式0：连续，零额外首数据延迟；模式1：首数据等待5个模型负沿，接受8字节后暂停4个负沿，请求仍有协议开销；模式2：首延迟5，种子 0x20261012 的 LFSR 随机暂停、请求间隔、DUT 输入暂停及周期输出背压。模型细节见 tb/w4a8_memory_model.sv。随机进展依赖握手，单/双缓冲的暂停事件时间线不完全相同。

重叠计数仅统计 RUN 同拍接受数据，不能涵盖在 SAVE_G/scale/输出期间提前加载的收益。计数器均32位，无符号模2^32；每次合法启动清零，读数在 done 后保持。total_cycles 不计接受 start 的拍，计所有 busy 拍及 FINISH。compute/input_wait/output_wait 分别为 RUN、WAIT_TILE且目标bank未READY、OUT_SEND且未ready，三者互斥；overlap 是compute子集，不能加到总周期。输入字节只计真正握手接受，scale 两字节分别计数。

## 瓶颈证据

默认 Prefill 连续供数：总2555，RUN 288，等输入1417，其他控制/存储/scale阶段850。总输入2304字节，通过单字节端口。每组16拍保存psum，48拍串行scale读/乘/合并；3个N tile×3组共576拍。不同group重复装载scale，每K tile复制A/scale，均是可优化开销。Decode仅1个有效PE行，理论计算阶段最大25%行利用率；功能通过不等于Decode最优架构。
